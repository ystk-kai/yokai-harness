次の社内ツールの画面を作ってください。

ツール: 経費精算システムの「承認待ち一覧」画面 (承認者である課長が使う)
利用者: 部下 8〜15 名の申請を、週に 2〜3 回まとめて承認する課長。PC のブラウザで使う。
画面に必要な要素:
- 承認待ちの申請の一覧 (申請者・申請日・費目 (交通費 / 接待交際費 / 消耗品費 / 出張旅費)・金額・領収書の有無・申請からの経過日数)。サンプルデータを 12 件入れる。
- 規程違反の疑い (例: 接待交際費が 1 人あたり 5,000 円を超える、領収書がない 1 万円以上の申請) がある行を見分けられるようにする。
- 複数行を選んでまとめて承認する操作と、1 件ずつ差し戻す操作 (差し戻しには理由の入力が要る)。
- 費目と申請者での絞り込み。
- 今月の部署の経費合計と、予算に対する消化率。
画面の目的: 課長が、問題のない申請を素早くまとめて承認し、疑いのある申請だけを詳しく見られるようにする。
