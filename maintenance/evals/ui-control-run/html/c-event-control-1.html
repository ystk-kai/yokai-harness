// ABOUT

開催概要

Rust は Web やツールだけの言語ではありません。メモリ安全性とゼロコスト抽象化は、マイコンの上でこそ効いてきます。

今回のテーマは「組込み Rust を現場に入れてみた」。製造業の社内エンジニア、組込み受託開発会社のエンジニア、大学院生の 3 人が、no_std での開発、C からの段階的な移行、embassy を使った非同期処理について、それぞれの現場の話をします。

対象は Rust を触ったことがある方です。組込みの経験は問いません。「マイコンは触ったことがないけど気になっている」という方も歓迎します。
