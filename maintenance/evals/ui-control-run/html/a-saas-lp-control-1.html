FEATURE 01

24 時間の Web 予約

診療時間外や休診日でも、患者さんはスマートフォンから空き枠を見て予約できます。お昼休みや夜間の「電話がつながらない」を減らし、予約の取りこぼしを防ぎます。

FEATURE 02

来院前の Web 問診

予約に続けて、ご自宅で落ち着いて問診に回答していただけます。回答は電子カルテへそのまま転記できる CSV で出力でき、紙の問診票からの手入力が不要になります。

CSV 出力に対応
FEATURE 03

予約前日の SMS リマインド

予約の前日に、患者さんの携帯電話へ SMS でお知らせを自動送信します。うっかり忘れによる無断キャンセルを防ぎ、確認のお電話をかける手間もなくなります。

よくある質問

よくあるご質問

どのくらいの規模の医院に向いていますか？
従業員 5〜30 名程度の歯科医院を想定して設計しています。受付の電話対応や、紙の問診票の転記に負担を感じている医院におすすめです。
料金はいくらですか？初期費用はかかりますか？
月額 9,800 円（税別）です。初期費用は 0 円で、導入時にまとまった費用はかかりません。
無料で試すことはできますか？
はい。30 日間の無料試用をご用意しています。ページ下部のフォームからお申し込みください。
問診の回答は、電子カルテに取り込めますか？
Web 問診の回答は、電子カルテへそのまま転記できる CSV 形式で出力できます。紙の問診票を見ながら手入力する作業を減らせます。
患者さんはどのように予約や問診を行いますか？
患者さんはスマートフォンから、24 時間いつでも予約と来院前の問診への回答を済ませられます。予約の前日には SMS でリマインドが届きます。
