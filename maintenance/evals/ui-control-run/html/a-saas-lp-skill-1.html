予約したいと思ったとき

診療時間外でも、24 時間 Web で予約を受け付けます

患者さんは空いている枠をスマートフォンで見て、そのまま予約できます。夜や休診日に思い立った予約も、翌朝の電話を待たずに埋まります。

今まで　電話がつながる診療時間中にしか予約を受けられず、診療の手を止めて電話に出ていた。

来院の前に

問診は Web で記入。回答は電子カルテへ転記できる CSV で出せます

予約を済ませた患者さんに、そのまま問診票の入力へ進んでもらいます。待合室で紙に書いてもらい、受付で打ち直す作業がなくなります。

今まで　紙の問診票を受け取り、読みにくい字を確かめながら電子カルテに転記していた。

よくある質問

どのくらいの規模の医院に向いていますか

従業員 5〜30 名の歯科医院を想定してつくっています。受付を少人数で回していて、電話と問診票の転記に時間を取られている医院に向いています。

いま使っている電子カルテと連携できますか

Web 問診の回答は、電子カルテへ転記できる CSV ファイルとして出力できます。紙の問診票を見ながら打ち直す作業の代わりに、CSV のデータを使って転記していただけます。

無料試用ではどの機能が使えますか

30 日間、Web 予約・Web 問診・SMS リマインド・キャンセル待ちの自動案内のすべてを使えます。初期費用はかかりません。

試用のあとの料金はいくらですか

月額 9,800 円（税別）の 1 プランです。機能ごとの追加料金はありません。

まず 30 日間、受付で使ってみてください

院長または事務長の方からお申し込みください。初期費用は 0 円で、試用期間中に料金はかかりません。
