Problems

受付で、こんなことに
時間を取られていませんか？

予約・変更の電話が鳴り止まない

診療中も電話対応で手が止まり、受付に患者さまの列ができてしまう。診療時間外の予約希望は取りこぼしてしまう。

紙の問診票を電子カルテに転記している

手書きの文字を読み取り、一項目ずつ入力し直す作業が毎日発生。読み間違いや入力漏れも気になる。

無断キャンセルで予約枠が空いてしまう

前日の確認電話までは手が回らない。急なキャンセルが出ても、待っている患者さまへ連絡する余裕がない。

その作業、カルテノートで減らせます。

Features

受付業務を軽くする、4つの機能

予約から来院前の準備まで、患者さまがスマートフォンで済ませられる仕組みをそろえました。

FEATURE 01

24 時間の Web 予約

診療時間外や休診日でも、患者さまはスマートフォンから空き枠を見て予約できます。予約の変更・取り消しもWeb上で完結します。

  • 夜間・休日の予約希望を取りこぼさない
  • 予約・変更の電話を減らせる
FEATURE 02

来院前の Web 問診

予約後、患者さまは自宅で問診に回答。回答は電子カルテへそのまま転記できる CSV 形式で出力できます。

  • 紙の問診票からの転記作業を減らせる
  • 来院前に症状を把握して準備できる
FEATURE 03

予約前日の SMS リマインド

予約日の前日に、患者さまの携帯電話へ SMS で予約内容を自動でお知らせ。確認の電話をかける手間がかかりません。

  • うっかり忘れによる無断キャンセルの防止に
  • 前日の確認電話が不要に
FEATURE 04

キャンセル待ちの自動案内

キャンセルで枠が空くと、キャンセル待ちに登録している患者さまへ自動でご案内。空いた枠を埋めるための連絡が不要です。

  • 急なキャンセルの空き枠を活かせる
  • 待っている患者さまへの連絡を自動化

How it works

患者さまも、医院も、手間が少ない

患者さまスマートフォンで完結

  1. Web で予約空き枠を見て、好きな時間に予約。
  2. 来院前に問診を記入自宅で落ち着いて回答。待合室で書く必要はありません。
  3. 前日に SMS でお知らせ予約日時を SMS で確認できます。
  4. 来院受付での記入なしで、スムーズに診療へ。

医院さま電話と転記が減る

  1. 予約が自動で入る電話を受けずに予約台帳へ反映。
  2. 問診の回答を確認来院前に症状を把握し、準備ができます。
  3. CSV で電子カルテへ回答を CSV で出力し、転記の手間を削減。
  4. リマインド・空き枠案内は自動前日連絡もキャンセル待ちへの案内もおまかせ。
