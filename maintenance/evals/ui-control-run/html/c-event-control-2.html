Rust は組込みの現場でも使われ始めていますが、「実際の製品や社内システムにどう入れたのか」という話を聞ける機会はまだ多くありません。

今回は、工場の温度センサー・C ファームウェアの段階的な置き換え・embassy による非同期開発という 3 つの事例を、それぞれの現場のエンジニアと研究者が紹介します。

// AUDIENCE

こんな方におすすめ

Rust を触ったことがある方

チュートリアルを試した程度でも大丈夫です。所有権や Result などの基本を知っていると、発表がより楽しめます。

組込みの経験は問いません

マイコンを触ったことがない Web / アプリ系のエンジニアも歓迎です。逆に、C で組込みをやってきて Rust が気になっている方もぜひ。

// 参加条件を Rust で書くと…
fn can_join(you: &Engineer) -> bool {
    you.has_touched_rust()   // 組込み経験は問わない
}
